VUmedi Library

A private, single-user tool that keeps a local, searchable index of medical-webinar invitations sent by Vumedi (videos@vumedi.com).

What it is

VUmedi Library reads the Gmail inbox of its single user with read-only access, extracts video-webinar invitations from videos@vumedi.com (title, presenter, organization, date, and watch link), classifies them by medical specialty, and stores them in a local SQLite database on the user's own server. Videos are opened on vumedi.com, where the user signs in with their own Vumedi account.

What the Gmail permission is used for

  • Scope requested: https://www.googleapis.com/auth/gmail.readonly — read-only. VUmedi Library cannot send, delete, or modify mail.
  • Only messages from videos@vumedi.com are read; nothing else in the mailbox is accessed beyond listing those messages.
  • Email content is processed locally on the user's own server and stored locally. No email data is sent to, stored on, or shared with any third party or external service by this application.
  • The Gmail access token and refresh token are stored only on the user's server, in an access-restricted credentials/ directory.

Data handling

  • This project does not collect, transmit, sell, or share user data.
  • There is no backend service: the application runs entirely on equipment owned and operated by its sole user, on a private home network.
  • Users can revoke access at any time from their Google account permissions page.
